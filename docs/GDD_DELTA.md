# GDD Delta — v0.2.0

This file records only intentional changes to the original master prompt.

1. Low-end integrated GPU support is no longer a Phase-1 requirement.
2. Primary target is the owner's RTX 4060 Laptop GPU / 32 GB RAM PC.
3. Visual appeal is promoted above broad hardware scalability for the first vertical slice.
4. Unreal Engine 5.8 becomes the fixed engine for the rebuild.
5. Character/environment production assets may use higher polygon counts and larger textures where the visual return is clear.
6. The emotional identity remains unchanged: travel, discovery, growth, attachment, achievement, comfort, and a small adventure.
7. The core delivery loop remains unchanged.
