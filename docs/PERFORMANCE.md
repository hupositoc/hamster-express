# Performance Target

Primary target: RTX 4060 Laptop GPU, i7-14700HX, 32 GB RAM, DX12.

Vertical slice target:
- 1920x1080: 60 FPS target
- Lumen GI: High
- Lumen reflections: High
- Hardware ray tracing: enabled when available
- Virtual Shadow Maps: enabled
- TSR: enabled

Profile before reducing character silhouette, lighting quality or animation quality. First reductions: distant foliage density, reflection quality, secondary shadow distance, particle density, and view distance.
